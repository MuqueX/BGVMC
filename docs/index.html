使用方法：

第一步：获取AI平台的apiKey

QwenTTS模型apiKey的获取（用于语音复制以及生成）

1.访问千问API开放平台。（本程序使用QwenTTS）

2.按提示登录或注册，完成实名认证并充值。（一般充值10元以内）

3.点击左侧API Keys板块，按提示创建apiKey，你会得到一个格式为：sk-ws-H.******************的字符串，请将其当场复制。

切记不要把你的apiKey告诉任何人！！！

4.将你的apiKey粘贴进入本网页设置界面的 DashScope（QwenTTS）API Key对应的输入框中，然后点击保存。至此QwenTTS设置完成。

Deepseek模型apiKey的获取

1.访问DeepseekAPI开放平台

2.按提示登录或注册，完成实名认证并充值。（一般充值10元以内）

3.点击左侧API Keys板块，按提示创建apiKey，你会得到一个格式为：sk-******************的字符串，请将其当场复制。

切记不要把你的apiKey告诉任何人！！！

4.将你的apiKey粘贴进入本网页设置界面的 DeepSeek API Key 对应的输入框中，然后点击保存。至此Deepseek设置完成。

第二步：编写提示词、上传音声以及预设配置

提示词编写

方案1：自己写

1.找到本网页设置里面的 初始提示词（系统角色） 板块

2.在靠上的那个输入框里面输入你对于对面的AI的要求。

例如：

你是一个虚拟歌姬，叫初音未来······（自己写）

也可以上网寻找你想要的角色的提示词。（B站上应该一堆）

3.点击保存提示词

方案2：AI帮写

1.找到本网页设置里面的 初始提示词（系统角色） 板块

2.在靠下的那个输入框里面尽可能详细地输入你对于这个角色的描述，甚至可以有对话示例。

3.按 ✨ 让 DeepSeek 编写并应用 ，稍等片刻即可发现已经自动填充。

3.点击保存提示词

上传音声

1.在本网页设置里找到 创建音色 模块

2.填写音色名称以及选择音频文件（两三句你想要的角色的语音就够了，不要太长！！）

3.点击创建音色，待出现✅ 创建成功 voice_id=qwen-tts-vc-********-voice-*******-****（已保存）时，说明已经创建完成，你可以去下面一个模块试听。

如果换设备发现音色列表清空就请完成apiKey获取后点击 查询此Key的音色 来找回

预设保存

1.在配置好上面全部提到的东西了之后，找到设置里 预设项目 模块。

2.填写预设名称，并点击 保存预设 以后在本设备使用就只需要选择预设即可。

至此，所有配置已经完成。
